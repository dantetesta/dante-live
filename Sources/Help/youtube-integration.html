Primeiro: qual arquivo você precisa?

Vídeo + guia do Live: o vídeo acompanha a criação do projeto até o download do JSON. Na etapa 5, siga a permissão específica do Dante Live descrita aqui. As etapas 7 e 8 mostram como importar e conectar dentro do Live.

O Dante usa um cliente OAuth para computador: a configuração que permite pedir sua autorização no Google. O arquivo é gerado pelo próprio Google — você não precisa montar um JSON à mão.

A chave RTMP envia imagem e áudio. A conexão Google permite ao Dante trabalhar com os dados do canal e suas lives. O JSON sozinho não autoriza o acesso: você ainda fará login e aprovará as permissões.

Deixe à mão
  • A conta Google que administra o canal do YouTube.
  • O Dante Live instalado no Mac, com a transmissão parada durante a configuração.
  • Um navegador com acesso à internet e à pasta Downloads.

Conceito: credenciais da API do YouTube. Caminhos do aplicativo conferidos no código do Dante Live.

01

Crie um projeto no Google Cloud

O projeto reúne a configuração da sua integração.

  1. Abra o Google Cloud Console e entre na sua conta Google.
  2. No seletor de projetos, no topo da página, escolha Novo projeto / New project.
  3. Dê um nome fácil de reconhecer, como Dante Live pessoal, e conclua a criação.
  4. Aguarde a criação. No painel de Notificações (ícone de sino, no topo), clique em Selecionar projeto na confirmação. Você também pode usar o seletor do topo e clicar no nome do projeto. Confira o nome selecionado antes de continuar.
Confira: todas as próximas etapas precisam estar no mesmo projeto. O nome usado no vídeo é apenas um exemplo; escolha um nome seu. Se o Console pedir organização ou local, use a opção disponível para sua conta — em uma conta pessoal pode aparecer Nenhuma organização.

Referência: preparação do projeto para a API do YouTube. Use apenas a parte de configuração; o Dante não exige instalar Python.

02

Ative a API do YouTube

Ela permite ao aplicativo conversar com o YouTube.

APIs e serviços › Biblioteca › YouTube Data API v3
  1. Abra APIs e serviços → Biblioteca (APIs & Services → Library).
  2. Pesquise YouTube Data API v3 e abra o resultado oficial do Google.
  3. Clique em Ativar / Enable. Se aparecer Gerenciar / Manage, a API já está habilitada.

03

Identifique o aplicativo

Esses dados aparecem na autorização do Google.

Menu ☰ › APIs e serviços › Tela de permissão OAuth › Começar
  1. Abra o menu ☰ → APIs e serviços → Tela de permissão OAuth, como no vídeo. Esse caminho abre a Google Auth Platform. Em outras versões do Console, a opção pode aparecer como Tela de consentimento OAuth.
  2. Na visão geral, clique em Começar / Get started, se a configuração ainda não existe.
  3. Em Informações do app, digite o nome do aplicativo e escolha o e-mail de suporte. Clique em Avançar.
  4. Em Público, escolha Externo para este uso pessoal e clique em Avançar.
  5. Em Dados de contato, informe um e-mail seu e avance. Pode ser o mesmo e-mail usado como suporte.
  6. Em Concluir, leia os termos; se concordar, marque a confirmação, clique em Continuar e finalize em Criar.

04

Adicione sua conta como usuário de teste

Comece com acesso restrito às contas que você indicar.

Público-alvo / Audience › Usuários de teste › + Adicionar
  1. Na lateral da Google Auth Platform, abra Público-alvo / Audience. Para este uso inicial pessoal, mantenha o projeto em Teste / Testing.
  2. Role até Usuários de teste e clique em + Adicionar. O painel lateral Adicionar usuários será aberto.
  3. Informe o e-mail Google usado para entrar na conta que administra o canal e clique em Salvar. Confira se esse e-mail aparece na lista. Não informe o nome do canal nem o @ do YouTube.
  4. Se vai conectar contas Google diferentes, adicione os respectivos e-mails também.
Você poderá precisar conectar novamente após 7 dias. No modo de teste, a autorização desta integração expira, inclusive a renovação automática. Isso não apaga seu canal.

Referências: inclusão dos usuários e regras do modo de teste.

05

Escolha a permissão do Dante Live

Esta etapa é diferente da configuração do Studio mostrada no vídeo.

Para o Live, use a permissão abaixo. O tutorial mostra youtube.upload e youtube.readonly para o Dante Studio. O Dante Live solicita youtube para gerenciar os dados e agendamentos das lives. Não substitua a permissão do Live pelas duas do Studio.
Acesso a dados › Adicionar ou remover escopos › Atualize os escopos selecionados
  1. Na lateral da Google Auth Platform, clique em Acesso a dados / Data Access. Abra Adicionar ou remover escopos / Add or Remove Scopes.
  2. No painel Atualize os escopos selecionados, use Filtro para pesquisar youtube. Marque a linha cujo escopo completo corresponde exatamente ao endereço abaixo, sem .upload ou .readonly no final.
https://www.googleapis.com/auth/youtube

Essa permissão permite gerenciar sua conta do YouTube. É um acesso amplo: confira o projeto e a permissão antes de autorizar.

  1. Se preferir, use Adicionar escopos manualmente, cole o endereço completo e clique em Adicionar à tabela.
  2. Clique em Atualizar no rodapé do painel. Confira se o escopo aparece na página Acesso a dados. Se a sua versão do Console também apresentar Salvar, confirme esse botão.
Confira antes de continuar: a configuração do Dante Live deve incluir https://www.googleapis.com/auth/youtube. Não adicione permissões de outros serviços para completar este guia.

Referências: configurar escopos no Console e permissões OAuth do YouTube. Escopo conferido no código do Dante Live.

06

Crie o cliente e baixe o JSON

Esta é a etapa que gera o arquivo para o Dante.

Google Auth Platform › Clientes / Clients › Criar cliente
  1. Abra Clientes / Clients e clique em Criar cliente / Create client.
  2. Em tipo de aplicativo, escolha App para computador / Desktop app.
  3. No campo Nome, dê um nome à credencial, como Dante Live — meu Mac, e clique em Criar. É uma identificação para você reconhecer esse cliente; não precisa ser o nome exato do computador.
  4. Na janela Cliente OAuth criado, clique em Baixar JSON, na parte inferior, e confirme o download. Só depois feche em OK. Não basta copiar o ID ou a chave exibidos: o Dante importa o arquivo JSON completo.
É “computador”, mesmo sendo Mac. Não selecione iOS, aplicativo da Web, chave de API ou conta de serviço. O importador do Dante exige o formato OAuth de computador.
.json
client_secret_… .jsonNome ilustrativo. Use o arquivo real baixado pelo Google, sem editar seu conteúdo.
Baixe na hora da criação. O Google informa que o segredo completo só fica disponível nesse momento. Não conte com recuperá-lo depois. Se perdeu o arquivo, veja a orientação na seção de ajuda.

O fluxo de computador usa um retorno local no Mac. Você não precisa cadastrar um site. Se aparecerem campos de origens JavaScript, confira se escolheu o tipo “Web” por engano.

Referências: criar cliente Desktop, disponibilidade do segredo e retorno local no computador.

07

Importe o arquivo no Dante Live

Agora você sai do Console e volta ao aplicativo.

Configurações da live › Conta YouTube › Importar configuração Google…
  1. No Dante, clique no botão de ajustes da barra superior para abrir Configurações da live.
  2. Selecione a aba Conta YouTube.
  3. Clique em Importar configuração Google… e escolha o JSON da pasta Downloads.
  4. Se já havia uma configuração, o botão aparece como Trocar configuração Google….
O que conferir: após uma importação aceita e sem operação em andamento, o botão Conectar canal… fica disponível. Se houver erro, o Dante mostra a mensagem; não é necessário editar o JSON manualmente.

A configuração e os tokens de autorização ficam no Acesso às Chaves do Mac. A importação não apaga o arquivo original de Downloads. Guarde-o em local protegido e não o publique no GitHub nem envie por mensagens.

08

Autorize e confira seu canal

A autorização acontece no navegador do Google.

  1. Clique em Conectar canal….
  2. No navegador, escolha a conta que você adicionou como usuário de teste. Quando houver escolha de identidade ou canal, selecione o canal desejado.
  3. Confira o nome do projeto e as permissões solicitadas. Autorize somente se corresponderem à configuração que você criou.
  4. Volte ao Dante e confira o nome exibido em Canal. Para outra conta ou canal, use novamente Conectar canal… e depois escolha o canal na lista.
  5. Ative Usar YouTube ao clicar em Transmitir para usar a integração, em vez da conexão RTMP manual.
  6. Use Ver minhas lives… para consultar os eventos do canal sem iniciar uma transmissão. Uma lista vazia pode simplesmente significar que não há próximas lives.

O Google pode mostrar um aviso de aplicativo não verificado. Confira seu projeto e sua conta antes de autorizar.

Referência: avisos e acesso em modo de teste. Botões e comportamento conferidos no Dante Live.

Conectar não coloca você ao vivo.

Importar o JSON e autorizar o canal são etapas de configuração. A transmissão só deve ser iniciada pelo fluxo de Transmitir, com a seleção e confirmação da live.

  • JSON importado: o Dante conhece seu cliente Google.
  • Canal conectado: você concedeu acesso à conta.
  • Live no ar: é uma operação separada, a confirmar no YouTube.

Travou em alguma etapa?

Encontre o sintoma e confira a configuração correspondente.

O Dante diz que o JSON não é de “Aplicativo para computador”

Volte à etapa 6 e baixe a credencial Desktop. O importador espera um objeto installed com client_id e client_secret. JSON de conta de serviço ou cliente Web não serve. Não renomeie campos para tentar convertê-lo: crie o tipo correto.

Perdi o JSON ou o Google só mostra o final do segredo

Não monte um arquivo com o segredo mascarado. Para uma nova configuração pessoal, crie outro cliente Desktop, baixe o JSON imediatamente e importe-o no Dante; depois conecte o canal novamente. Preserve o cliente antigo se ainda for usado em outro lugar. Orientação oficial sobre os segredos.

Acesso negado, erro 403 ou conta fora da lista de teste

Se o erro menciona usuários de teste, confira o e-mail da etapa 4. org_internal indica restrição à organização. Contas corporativas podem exigir aprovação do administrador. Regras de público e restrições.

Conectou antes, mas agora pede login novamente

Use Conectar canal… novamente; veja o prazo da etapa 4. Produção pode exigir verificação do Google e não significa aprovação automática. Teste e produção.

Apareceu invalid_client ou redirect_uri_mismatch

Confira o tipo Desktop e se a credencial importada ainda existe no projeto. Importe o JSON correto, sem alterações. O Dante usa um endereço local temporário 127.0.0.1 para receber a autorização; não é preciso cadastrar esse endereço como um site. Fluxo OAuth para computador.

O canal exibido no Dante não é o que eu queria

Confira a lista Canal. Se o desejado não está nela, conecte novamente usando a conta/identidade correta no Google. Para uma Conta de marca, o usuário de teste precisa administrar essa conta. Acesso de Contas de marca.

Importar ou conectar está desabilitado

Essas ações ficam bloqueadas durante uma transmissão ativa do Dante ou uma operação de conexão em andamento. Configure em um momento sem live ativa e aguarde a operação terminar. Não é necessário alterar o OBS.

Sobre este manual

Guia independente do Dante Live, revisado a partir do manual atualizado do Dante Studio e da transcrição e telas do tutorial do autor. A organização e os nomes do Console podem variar com o idioma e as atualizações do Google; os nomes em inglês ajudam a localizar as opções. Os exemplos de nomes são sugestões, e a ilustração do arquivo não contém uma credencial.

O que foi conferido: os cliques no Console até o download do JSON foram revisados com a transcrição e as telas do tutorial Integração com YouTube, de 5 min 54 s. A etapa 5 foi adaptada ao escopo usado pelo Dante Live; importação e conexão foram conferidas nos controles do aplicativo. Esta revisão não realizou login nem agendamento em uma conta real.
